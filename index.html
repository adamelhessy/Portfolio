About me

I'm a computer engineering student at Ain Shams University with a habit of building things to see how they work. I like turning a vague requirement into clear classes, clean data flow, and a screen someone can use.

My biggest project so far is a hotel reservation system written in Java with a team of five. I worked on the admin tools, the receptionist role, amenity pricing and revenue reports, and spent a lot of time debugging the whole system.

Outside coursework I build and deploy web projects with HTML, CSS and JavaScript, and keep my work on GitHub with regular commits.

I'm looking for internships and projects where I can keep learning on real code and work with people who review each other's work.
